Rainbow AI Privacy Center

1. What is Stored Locally in Your Browser

Conversations, Rainbow Projects, Prompt Studio templates, Rainbow Canvas drafts, and UI preferences are saved in your browser's localStorage under the rainbow_ai_v2_* namespace. No API secrets are ever embedded in client code or saved in browser storage.

Calculating local storage usage...
2. What is Sent to the Inference Backend

When you submit a message, your prompt, active conversation context, persona/study instructions, and any attached text snippets are sent over HTTPS to your configured Cloudflare Tunnel gateway reaching Rainbow-AI-Unified-12B on Hugging Face.

3. Content Security & Sanitization

All Markdown output, code blocks, and imported backups are sanitized with DOMPurify before rendering.
